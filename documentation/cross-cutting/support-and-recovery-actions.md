# Support and recovery actions

You use this guide when a normal workflow is no longer enough and the platform needs investigation, repair, or manual intervention.

## Common recovery tools
- System Admin order detail pages give support context for one order.
- System Admin finance pages support invoice review and correction.
- System Admin moderation pages support review resolution and rating refresh.
- System Admin tools can start reindex, cache rebuild, import, integrity, or other operational jobs.

## Recovery pattern
1. Confirm the visible problem and the surface where it appears.
2. Open the page or workflow that owns the source record.
3. Check whether the issue is a state problem, a permission problem, or a propagation problem.
4. Use the right admin tool or workflow only after you understand which class of problem you are fixing.
