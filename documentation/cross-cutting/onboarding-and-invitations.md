# Onboarding and invitations

You use this guide when a user moves from approval or invitation into a working account.

## Where it shows up
- System Admin approves vendor applications.
- Vendor Admin sends driver invitations.
- Vendor users enter the Vendor Admin onboarding flow.
- Drivers enter the Driver Portal onboarding flow.

## What happens
1. An internal or vendor-side workflow triggers the invitation.
2. The invited person opens the invitation-linked onboarding landing page.
3. The person completes registration.
4. The site shows a welcome state and the person moves into the signed-in area.

## What to watch
- Invitation delivery can be delayed compared with the admin action that triggered it.
- The onboarding link should match the correct persona and portal.
- Access problems usually come from invitation state, account state, or role boundaries rather than from the public landing page alone.
