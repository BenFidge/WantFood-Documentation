# Payment methods

You use this page to configure which payment methods the current vendor can accept and how the payment connection is set up.

## What you need first
- A signed-in vendor-linked account.
- The correct vendor or branch context.

## How you reach it
Vendor dashboard -> Payment methods.

## What you can do here
- review current payment settings
- connect or update payment configuration
- remove payment configuration that should no longer stay active

## What good looks like
The vendor payment setup matches the payment methods the business intends to offer.
