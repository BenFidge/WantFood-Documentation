# Vendor dashboard

You use this page as the main working home for the currently selected vendor or branch.

## What you need first
- A signed-in vendor-linked account.
- A valid vendor context.

## How you reach it
Vendor Admin sign-in -> dashboard.

## What you can do here
- review the current operating context
- see and change whether the current branch is **taking orders** using the Taking Orders toggle in the branch context card
- see and change whether the current branch accepts **scheduled orders** using the Scheduled Orders toggle in the branch context card
- move into menus, orders, drivers, offers, reviews, and settings
- use the dashboard as the starting point for day-to-day work

## Branch context card
The branch context card appears at the top of the dashboard. It shows the current branch name, a **Taking Orders** toggle, and a **Scheduled Orders** toggle. Both toggles update immediately without a page reload. The context card is always visible — even when you only manage one branch — so you can change branch status from the dashboard at any time.

## What good looks like
You can start the right operational task quickly from the current vendor context, and you can switch a branch on or off for orders without navigating to the restaurant settings.
