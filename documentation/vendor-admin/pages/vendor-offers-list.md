# Vendor offers list

You use this page to manage the offers that belong to the current vendor.

## What you need first
- A signed-in vendor-linked account.
- The correct vendor or branch context.

## How you reach it
Vendor dashboard -> Vendor offers.

## What you can do here
- review active and inactive offers
- create a new offer
- open an offer for edit, pause, activate, or clone work

## What good looks like
The vendor offer set stays aligned with the promotions the business wants to run.
