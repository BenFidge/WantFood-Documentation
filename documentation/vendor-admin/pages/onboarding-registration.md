# Onboarding registration

You use this page to create the account details needed to finish vendor onboarding.

## What you need first
- An approved application.
- A valid onboarding invitation.

## How you reach it
Onboarding landing -> registration.

## What you can do here
- enter the required account details
- submit the registration data
- continue into the welcome state

## What good looks like
The invited vendor user can complete account setup and move into the main admin area.
