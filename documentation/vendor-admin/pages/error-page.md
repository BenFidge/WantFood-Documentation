# Error page

You see this page when onboarding or another Vendor Admin request cannot complete.

## What you need first
- None beyond access to the failed route.

## How you reach it
Any failed public or signed-in Vendor Admin path.

## What you can do here
- understand that the current workflow did not complete
- decide whether to retry, go back, or ask for help
- capture the visible error state if support needs it

## What good looks like
You know the current action failed and you can choose a safe next step.
