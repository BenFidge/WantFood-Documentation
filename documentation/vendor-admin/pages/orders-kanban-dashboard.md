# Orders kanban dashboard

You use this page to manage live incoming and in-progress orders in a kitchen-focused board view.

## What you need first
- A signed-in vendor-linked account.
- The correct vendor or branch context.
- Order-handling permission for the branch.

## How you reach it
Vendor dashboard -> Orders kanban dashboard.

## What you can do here
- review active orders by state
- open order detail context
- run accept, reject, ready, assign, unassign, cancel, or edit workflows

## What good looks like
You can move live orders through the operational states your branch needs.
