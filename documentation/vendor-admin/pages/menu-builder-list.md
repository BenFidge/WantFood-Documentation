# Menu builder list

You use this page to review the menus that belong to the current vendor context and choose which one to maintain.

## What you need first
- A signed-in vendor-linked account.
- The correct vendor or branch context.

## How you reach it
Vendor dashboard -> Menu builder list.

## What you can do here
- open an existing menu
- create a new menu
- review the current publication or status state

## What good looks like
You can move into the correct menu maintenance workflow quickly.
