# All orders

You use this page to review a broader history of orders beyond the live kanban view.

## What you need first
- A signed-in vendor-linked account.
- The correct vendor or branch context.

## How you reach it
Vendor dashboard -> All orders.

## What you can do here
- search for older orders
- review order history in context
- open the right order record for follow-up

## What good looks like
You can find the order record you need even when it is no longer part of the live board.
