# Menu editor

You use this page as the main workspace for structured menu editing and publishing.

## What you need first
- A signed-in vendor-linked account.
- The correct vendor or branch context.
- A menu to edit or create.

## How you reach it
Menu builder list -> open a menu.

## What you can do here
- edit menu details
- create, update, reorder, move, or remove categories and dishes
- manage images, availability, and publication state

## What good looks like
You can complete most menu maintenance from one operational workspace.
