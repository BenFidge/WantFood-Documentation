# Manage live orders

You use this workflow to accept, reject, edit, mark ready, assign drivers, unassign drivers, or cancel orders that are moving through the live kitchen flow.

## When you use this feature
- a new order arrives
- a kitchen or dispatch decision is needed
- the current order state should change

## Where the workflow starts
Orders kanban dashboard.

## How it works
1. Open the live orders board.
2. Review the order and its current state.
3. Apply the correct operational action for the kitchen or dispatch need.
4. Confirm that the board and related order views reflect the new state.

## Expected result
The order moves into the state that matches the real-world kitchen and dispatch workflow.
