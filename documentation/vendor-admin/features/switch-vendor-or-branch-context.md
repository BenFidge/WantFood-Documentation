# Switch vendor or branch context

You use this workflow when you need the admin site to operate against a different vendor or branch than the one currently selected.

## When you use this feature
- you manage more than one vendor or branch
- the visible data does not match the branch you intend to work on
- you need to change context before editing operational data

## Where the workflow starts
Vendor dashboard or no-vendor-context state.

## How it works
1. Open the current context control.
2. Choose the vendor or branch you want to manage.
3. Confirm the switch.
4. Recheck that menus, orders, drivers, and settings now match the expected context.

## Expected result
The site reflects the vendor or branch you intended to work on.
