# Manage dish content and images

You use this workflow to create, edit, move, or remove dish content and the images attached to it.

## When you use this feature
- a dish needs maintenance
- menu content needs better imagery
- a dish should move to a different category or disappear from the menu

## Where the workflow starts
Menu editor.

## How it works
1. Open the dish or category area in the menu editor.
2. Create, edit, move, or remove the dish content you need to change.
3. Upload or update imagery if the dish needs it.
4. Save the change and allow image processing and propagation to complete.

## Expected result
Dish content and images reflect the current menu plan.
