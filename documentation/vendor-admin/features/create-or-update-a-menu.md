# Create or update a menu

You use this workflow when the current vendor context needs a new menu or a maintenance update to an existing one.

## When you use this feature
- a new menu is needed
- menu details need to change
- a seasonal or branch-specific menu is being maintained

## Where the workflow starts
Menu builder list -> Menu editor.

## How it works
1. Open the menu builder list.
2. Create a new menu or open an existing menu.
3. Update the menu-level information and structure.
4. Save the changes before you move into publication or further dish work.

## Expected result
The menu record reflects the current structure and details you want to manage.
