# Invite and manage drivers

You use this workflow to add drivers, maintain their details, resend invitations, remove them, or change their branch assignment.

## When you use this feature
- a new driver should join
- driver details need maintenance
- a branch assignment should change
- driver access should be removed

## Where the workflow starts
Drivers list.

## How it works
1. Open the drivers list.
2. Create the invitation or open the driver record that needs maintenance.
3. Apply the invitation, edit, resend, assignment, or removal action.
4. Confirm that the driver list now reflects the intended operating setup.

## Expected result
Driver access and branch assignment match the current dispatch model.
