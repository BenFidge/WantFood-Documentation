# Promo code availability checks

You use this workflow to confirm whether a promo code is available before you rely on it operationally.

## When you use this feature
- you are creating or changing an offer
- a promo code might conflict with an existing code
- support needs to explain why a code is not available

## Where the workflow starts
Vendor offers list or offer maintenance flow.

## How it works
1. Open the offer workflow that uses the promo code.
2. Check the code availability through the admin flow.
3. Adjust the code if it conflicts or fails validation.
4. Save the offer with a valid promo code.

## Expected result
The promotion uses a code that the platform can accept.
