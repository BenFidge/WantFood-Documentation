# Manage vendor offers

You use this workflow to create, edit, pause, activate, or clone promotions that belong to the current vendor.

## When you use this feature
- the vendor is launching a promotion
- an offer needs maintenance
- an old offer should be reused as the basis for a new one

## Where the workflow starts
Vendor offers list.

## How it works
1. Open the vendor offers list.
2. Create a new offer or open an existing one.
3. Apply the edit, pause, activate, or clone action you need.
4. Confirm that the offer set now matches the promotion plan.

## Expected result
The vendor offer catalogue reflects the promotions the business intends to run.
