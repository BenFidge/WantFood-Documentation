# Reorder categories and dishes

You use this workflow when the menu should present categories or dishes in a different sequence.

## When you use this feature
- menu presentation needs curation
- seasonal items should appear earlier
- the current order no longer matches the intended customer journey

## Where the workflow starts
Menu editor.

## How it works
1. Open the menu in the editor.
2. Reorder the categories, dishes, or both.
3. Save the updated structure.
4. Recheck the downstream presentation after publication and propagation complete.

## Expected result
Categories and dishes appear in the intended sequence for the current menu.
