# Configure payment methods

You use this workflow to update which payment methods the current vendor can offer and how the payment connection is configured.

## When you use this feature
- a vendor is onboarding payments
- a payment provider setup needs correction
- a payment method should no longer remain available

## Where the workflow starts
Payment methods.

## How it works
1. Open the payment methods page.
2. Review the current connection and payment options.
3. Save, update, or remove the payment configuration.
4. Confirm that the payment setup now reflects the intended offer.

## Expected result
The vendor payment setup matches the business decision and is ready for downstream checkout use.
