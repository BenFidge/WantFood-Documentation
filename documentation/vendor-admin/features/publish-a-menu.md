# Publish a menu

You use this workflow when a menu is ready to become visible in downstream customer-facing experiences.

## When you use this feature
- menu changes are approved
- a draft menu should go live
- availability or status changes should take effect publicly

## Where the workflow starts
Menu editor.

## How it works
1. Review the menu in the editor.
2. Confirm that categories, dishes, images, and availability are correct.
3. Run the publish action.
4. Allow propagation and cache refresh behaviour to make the latest menu visible downstream.

## Expected result
The latest menu version is ready for downstream use.
