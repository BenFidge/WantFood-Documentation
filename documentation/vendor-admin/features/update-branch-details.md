# Update branch details

You use this workflow to change branch-specific restaurant information from the restaurant management area.

## When you use this feature
- branch data has changed
- you need to correct public-facing branch information
- operations need more accurate branch details

## Where the workflow starts
Manage restaurant.

## How it works
1. Open the current restaurant management page.
2. Edit the branch fields that need maintenance.
3. Save the updated record.
4. Allow downstream discovery and menu views to catch up through normal propagation.

## Expected result
The branch record reflects the latest approved information.
