# Configure delivery costs

You use this workflow to update the delivery pricing rules for the current vendor or branch.

## When you use this feature
- pricing rules have changed
- delivery trading terms need maintenance
- support needs a visible delivery-cost correction

## Where the workflow starts
Delivery costs.

## How it works
1. Open the delivery costs page.
2. Review the current pricing settings.
3. Save the new delivery cost configuration.
4. Recheck downstream quoting behaviour after normal propagation.

## Expected result
Future customer quotes reflect the updated delivery pricing model.
