# Flag a review for System Admin

You use this workflow when customer feedback needs moderation or escalation beyond the vendor side.

## When you use this feature
- a review looks abusive or unsafe
- a review needs platform moderation
- you want System Admin to inspect a feedback issue

## Where the workflow starts
Reviews list.

## How it works
1. Open the review that needs escalation.
2. Flag the review through the vendor workflow.
3. Confirm that the review now sits in the admin moderation path.
4. Track the outcome through the normal support process if needed.

## Expected result
The review is escalated into the System Admin moderation workflow.
