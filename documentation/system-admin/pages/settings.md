# Settings

You use this page to review and save shared settings that affect admin-managed behaviour.

## What you need first
- A System Admin account.
- Permission to manage settings.

## How you reach it
Home or dashboard -> Settings.

## What you can do here
- review editable settings
- save changes tied to content safety or other shared controls
- confirm that the platform accepted the updated values

## What good looks like
Shared settings stay aligned with the current operational rules.
