# Platform offers list

You use this page to manage platform-level offers that affect customer-facing promotions.

## What you need first
- A System Admin account.
- Permission to manage promotions.

## How you reach it
Home or dashboard -> Platform offers.

## What you can do here
- review active and inactive offers
- open an offer for maintenance
- start lifecycle changes such as activate, pause, or delete

## What good looks like
You can keep platform promotions current and aligned with campaign intent.
