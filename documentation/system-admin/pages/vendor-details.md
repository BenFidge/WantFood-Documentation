# Vendor details

You use this page to review the platform view of one vendor before making changes.

## What you need first
- A System Admin account.
- Permission to manage vendors.

## How you reach it
Vendors list -> open a vendor.

## What you can do here
- review current vendor status and core fields
- confirm whether the vendor should stay active or inactive
- move into the activation or deactivation workflow

## What good looks like
You can confirm the vendor state before making a sensitive operational change.
