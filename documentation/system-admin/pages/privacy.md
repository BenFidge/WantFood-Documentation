# Privacy

You use this page to review the privacy notice for the System Admin site.

## What you need first
- Access to the System Admin site.

## How you reach it
Privacy link from the site shell or footer.

## What you can do here
- read the current privacy notice
- confirm what data handling information the site presents to admin users

## What good looks like
You can review the privacy statement without leaving the admin experience.
