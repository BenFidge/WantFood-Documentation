# Hero slide editor

You use this page to create or update one hero slide.

## What you need first
- A System Admin account.
- Permission to manage homepage content.

## How you reach it
Hero slides list -> create or edit a slide.

## What you can do here
- edit slide content and targeting
- choose assets and save metadata
- prepare the slide for publish or unpublish decisions

## What good looks like
The slide is ready to show the right campaign message in the right context.
