# Brochure scan

You use this page to create a new vendor and seed its first menu from uploaded brochure or menu files.

## What you need first
- A System Admin account.
- Permission to manage vendors.
- A brochure, menu image, or PDF file with readable menu content.

## How you reach it
Vendors list -> Brochure scan.

## What you can do here
- upload brochure files and run AI extraction
- review extracted business details and menu content before saving
- edit business details before vendor creation
- re-scan to replace extracted content while you stay in the wizard
- confirm and create vendor plus menu in one flow
- send onboarding invitation email to the vendor contact after save

## What good looks like
You can create an accurate vendor record and an initial unpublished menu from one scan session without losing wizard state between steps.
