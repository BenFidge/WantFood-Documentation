# Orders list

You use this page to find orders that need support, investigation, or financial follow-up.

## What you need first
- A System Admin account.
- Permission to review orders.

## How you reach it
Home or dashboard -> Orders.

## What you can do here
- search for an order
- open the order detail record
- check the current state before you escalate or intervene

## What good looks like
You can find the right order record and understand where it sits in the wider lifecycle.
