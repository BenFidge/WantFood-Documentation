# Hero slides list

You use this page to manage the homepage hero slide set.

## What you need first
- A System Admin account.
- Permission to manage homepage content.

## How you reach it
Home or dashboard -> Hero slides.

## What you can do here
- review the current hero slide list
- open a slide for create or edit work
- manage publish state and ordering

## What good looks like
Homepage campaign content stays current, ordered, and ready for customer-facing use.
