# Vendors list

You use this page to find and review vendor records that are already on the platform.

## What you need first
- A System Admin account.
- Permission to manage vendors.

## How you reach it
Home or dashboard -> Vendors list.

## What you can do here
- search for a vendor
- open vendor details
- start AI menu scan onboarding from brochure files
- identify vendors that need activation, deactivation, or maintenance

## What good looks like
You can locate the right vendor record and move into the next administrative action quickly.
