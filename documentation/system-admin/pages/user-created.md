# User Created

You see this page immediately after a new admin user is added. It shows the new user's details and their temporary password.

## What you need first
- You must have just completed the Add User form on the Users list.

## How you reach it
Users list → Add User → (form submitted successfully) → User Created.

## What you see here
- The new user's name and email address.
- Their **temporary password** in a read-only field.
- A **Copy** button to copy the password to the clipboard.
- A warning that the password is shown only once and is never stored.
- An **Add Another User** button.
- A **View All Users** button.

## What to do here
Copy the temporary password before you leave this page. Share it with the new user through a secure channel — not email. The new user will be prompted to set their own password the first time they sign in.

> **Important.** Once you navigate away from this page the temporary password cannot be retrieved. If you leave without copying it, the only option is to delete the user from the Users list and add them again.

## What good looks like
The temporary password is copied and shared securely. The new user can sign in to System Admin and is prompted to set their own password on first use.
