# Commission tiers list

You use this page to review the tier rules that drive vendor commission behaviour.

## What you need first
- A System Admin account.
- Permission to manage commissions.

## How you reach it
Commissions dashboard -> Commission tiers.

## What you can do here
- review existing tiers
- open a tier for maintenance
- decide whether to create, update, or remove a tier

## What good looks like
You can keep the tier catalogue aligned with the platform commercial model.
