# Cuisine types list

You use this page to manage the cuisine taxonomy and its presentation order.

## What you need first
- A System Admin account.
- Permission to manage taxonomy.

## How you reach it
Home or dashboard -> Cuisine types.

## What you can do here
- review the current cuisine list
- change ordering for the web or mobile experiences
- keep the taxonomy aligned with the current catalogue

## What good looks like
Cuisine discovery options stay clean, relevant, and correctly ordered.
