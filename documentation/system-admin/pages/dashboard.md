# Dashboard

You use the dashboard to get an operational view of the platform and move quickly into the area that needs attention.

## What you need first
- A System Admin account.
- Permission to access the operational areas you need.

## How you reach it
Home or dashboard.

## What you can do here
- review headline operational signals
- open the next workflow for applications, vendors, orders, finance, content, or tools
- start investigation or recovery work from the main admin entry point

## What good looks like
You can see where attention is needed and move into the right workflow without hunting through the site.
