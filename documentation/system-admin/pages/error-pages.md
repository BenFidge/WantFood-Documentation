# Error pages

You see these pages when the site cannot complete the current request or when a route fails.

## What you need first
- None beyond access to the relevant route.

## How you reach it
Any failed route, denied action, or unexpected error path.

## What you can do here
- understand that the current task failed
- decide whether to retry, navigate away, or escalate
- capture the visible error state for support if needed

## What good looks like
You know the current action did not complete and you can choose the next safe step.
