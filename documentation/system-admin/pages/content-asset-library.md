# Content asset library

You use this page to manage shared media assets for homepage and campaign content.

## What you need first
- A System Admin account.
- Permission to manage content.

## How you reach it
Home or dashboard -> Content asset library.

## What you can do here
- review uploaded assets
- upload new assets
- edit metadata or remove assets that should no longer be used

## What good looks like
Shared content assets stay ready for hero slides, support-local content, and other admin-managed surfaces.
