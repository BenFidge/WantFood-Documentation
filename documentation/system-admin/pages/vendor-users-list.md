# Vendor users list

You use this page to review vendor-linked users and correct ownership or access problems.

## What you need first
- A System Admin account.
- Permission to manage vendor-linked users.

## How you reach it
Home or dashboard -> Vendor users list.

## What you can do here
- find the user attached to a vendor
- start the transfer workflow when a user belongs to the wrong vendor
- remove vendor-linked access that should no longer exist

## What good looks like
Vendor-linked access stays accurate and tied to the correct business record.
