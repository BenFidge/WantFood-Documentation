# Applications list

You use this page to review submitted vendor applications and decide which record needs action next.

## What you need first
- A System Admin account.
- Permission to review vendor applications.

## How you reach it
Home or dashboard -> Applications list.

## What you can do here
- scan submitted applications
- open the right application record
- prioritise records that need approval or rejection

## What good looks like
You can find the correct application quickly and move into the decision flow.
