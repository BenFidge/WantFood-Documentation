# Users list

You use this page to manage internal admin users who can access the System Admin site.

## What you need first
- A System Admin account.
- Permission to manage internal users.

## How you reach it
Home or dashboard -> Users list.

## What you can do here
- review who has admin access
- add a new admin user
- remove an admin user who no longer needs access

## What good looks like
Internal access stays limited to the people who should administer the platform.
