# Tools dashboard

You use this page to run operational tools that help refresh, repair, or backfill platform data.

## What you need first
- A System Admin account.
- Permission to run platform tools.

## How you reach it
Home or dashboard -> Tools.

## What you can do here
- trigger vendor reindex
- rebuild caches
- import postcode data or run integrity checks
- use manual recovery actions when stale or broken data needs intervention

## What good looks like
You can start the operational recovery action that matches the problem you are trying to solve.
