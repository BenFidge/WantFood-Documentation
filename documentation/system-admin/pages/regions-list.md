# Regions list

You use this page to manage regions that influence content targeting and discovery.

## What you need first
- A System Admin account.
- Permission to manage content or taxonomy.

## How you reach it
Home or dashboard -> Regions.

## What you can do here
- review the current region list
- create or edit a region
- remove obsolete regions when safe

## What good looks like
Region data stays accurate for the parts of the platform that rely on location targeting.
