# Commissions dashboard

You use this page to monitor how commission settings apply across vendors and to spot records that need review.

## What you need first
- A System Admin account.
- Permission to manage commercial settings.

## How you reach it
Home or dashboard -> Commissions.

## What you can do here
- review commission signals and summaries
- open tier configuration or assignment workflows
- check whether a recalculation is needed

## What good looks like
You can keep commission settings current and consistent with commercial intent.
