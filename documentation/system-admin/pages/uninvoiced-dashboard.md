# Uninvoiced dashboard

You use this page to see activity that has not yet been turned into invoices.

## What you need first
- A System Admin account.
- Permission to review invoices and finance data.

## How you reach it
Home or dashboard -> Invoices -> Uninvoiced.

## What you can do here
- review uninvoiced totals
- check which vendors are waiting for invoicing
- decide whether to generate a single invoice or a wider invoice run

## What good looks like
You can see what still needs invoicing before you start the next finance workflow.
