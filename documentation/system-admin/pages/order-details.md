# Order details

You use this page to review the operational and support context for one order.

## What you need first
- A System Admin account.
- Permission to review orders.

## How you reach it
Orders list -> open an order.

## What you can do here
- read the current order state and related data
- understand what happened across the wider workflow
- decide whether you need to move into vendor, delivery, finance, or support follow-up

## What good looks like
You can explain the state of the order and decide the next support action clearly.
