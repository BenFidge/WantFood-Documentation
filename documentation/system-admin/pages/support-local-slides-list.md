# Support Local slides list

You use this page to manage support-local promotional slides and their ordering.

## What you need first
- A System Admin account.
- Permission to manage homepage content.

## How you reach it
Home or dashboard -> Support Local slides.

## What you can do here
- review the current slide set
- create or edit a slide
- manage publish state, ordering, and deletion

## What good looks like
Support-local homepage content stays curated and operational.
