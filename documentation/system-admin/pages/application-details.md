# Application details

You use this page to review the submitted business information for one vendor application.

## What you need first
- A System Admin account.
- Permission to review vendor applications.

## How you reach it
Applications list -> open an application.

## What you can do here
- read the submitted business details
- check whether the record is ready for onboarding
- launch the approval or rejection workflow

## What good looks like
You have enough information to make a clear application decision.
