# Bad words list

You use this page to maintain the blocked-word list that supports content safety controls.

## What you need first
- A System Admin account.
- Permission to manage content safety settings.

## How you reach it
Home or dashboard -> Bad words.

## What you can do here
- review the blocked-word list
- add, edit, import, or remove entries
- save changes so the moderation rules stay current

## What good looks like
The platform has an up-to-date blocked-word list that supports safer content workflows.
