# Payment settings

You use this page to configure and maintain platform payment provider settings.

## What you need first
- A System Admin account.
- Permission to manage payment settings.

## How you reach it
Home or dashboard -> Payment settings.

## What you can do here
- review current payment provider configuration
- save Stripe or WorldPay settings
- remove provider configuration that should no longer be active

## What good looks like
The platform payment layer stays connected to the providers and credentials it should use.
