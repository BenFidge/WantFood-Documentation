# How to use System Admin

You use System Admin to review applications, maintain vendors and users, support order and invoice operations, manage promotions and content, and run recovery tools when downstream data falls out of date.

## Start with the right workflow
- Use [Applications list](pages/applications-list.md) when you are reviewing new vendor applications.
- Use [Vendors list](pages/vendors-list.md) and [Vendor details](pages/vendor-details.md) when you are changing vendor state.
- Use [Orders list](pages/orders-list.md) and [Order details](pages/order-details.md) when support or operations need order context.
- Use [Commissions dashboard](pages/commissions-dashboard.md), [Uninvoiced dashboard](pages/uninvoiced-dashboard.md), and [Invoice list](pages/invoice-list.md) for finance operations.
- Use [Platform offers list](pages/platform-offers-list.md), [Hero slides list](pages/hero-slides-list.md), and [Content asset library](pages/content-asset-library.md) for campaign and content work.
- Use [Tools dashboard](pages/tools-dashboard.md) when you need reindex, cache rebuild, import, or integrity actions.

## Core operating patterns
1. Start from the [Dashboard](pages/dashboard.md) when you need the quickest route into the next task.
2. Open the page that owns the record you need to change.
3. Use the matching feature workflow when the action changes state, visibility, or commercial behaviour.
4. If a change depends on background work, review the related cross-cutting note before you treat the outcome as complete.
