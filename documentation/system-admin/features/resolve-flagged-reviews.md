# Resolve flagged reviews

You use this workflow to review and resolve customer reviews that have been escalated for moderation.

## When you use this feature
- a review has been flagged
- support or safety teams need a moderation decision
- a rating or content issue needs admin attention

## Where the workflow starts
Flagged reviews list.

## How it works
1. Open the flagged review queue.
2. Review the content and surrounding context.
3. Apply the correct moderation outcome.
4. Confirm whether follow-up rating maintenance is needed.

## Expected result
The review queue moves forward and the content state reflects the moderation decision.
