# Manage cuisine ordering

You use this workflow to keep cuisine options well ordered for discovery surfaces.

## When you use this feature
- cuisine ordering feels out of date
- the mobile and web ordering should change
- taxonomy curation needs maintenance

## Where the workflow starts
Cuisine types list.

## How it works
1. Review the cuisine set.
2. Change ordering for the relevant surface.
3. Save the change.
4. Allow downstream discovery views to catch up through normal propagation.

## Expected result
Cuisine options appear in the intended order for the relevant customer-facing surface.
