# Configure payment providers

You use this workflow to add, update, or remove platform payment provider settings.

## When you use this feature
- a provider configuration is new
- existing provider settings have changed
- a provider should no longer remain connected

## Where the workflow starts
Payment settings.

## How it works
1. Open payment settings.
2. Review the current provider configuration.
3. Save or remove the provider settings through the admin workflow.
4. Confirm the platform now reflects the intended provider state.

## Expected result
The platform payment configuration matches the provider setup the business intends to use.
