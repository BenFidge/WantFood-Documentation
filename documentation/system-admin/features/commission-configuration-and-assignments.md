# Commission configuration and assignments

You use this workflow to connect commission rules to the vendors they should apply to.

## When you use this feature
- a vendor commission setup needs to change
- a new tier should apply to a vendor
- a recalculation is needed after a policy change

## Where the workflow starts
Commissions dashboard.

## How it works
1. Review the current commission view for the affected vendor or group.
2. Update the configuration or assignment through the admin workflow.
3. Trigger recalculation when the business case requires it.
4. Confirm that the commercial view now reflects the intended rule set.

## Expected result
Vendor commission configuration reflects the current commercial arrangement.
