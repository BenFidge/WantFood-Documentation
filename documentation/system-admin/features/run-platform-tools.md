# Run platform tools

You use this workflow when you need to refresh, rebuild, reindex, import, or validate platform data through the admin tools surface.

## When you use this feature
- search results are stale
- cached data has not caught up
- postcode data needs import
- an integrity or manual recovery action is required

## Where the workflow starts
Tools dashboard.

## How it works
1. Open the tools dashboard.
2. Choose the tool that matches the operational problem.
3. Trigger the tool and note whether it starts background work.
4. Recheck the affected downstream experience after the operation completes.

## Expected result
The platform begins the recovery or maintenance action that should resolve the visible problem.
