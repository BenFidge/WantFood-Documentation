# Manage hero slides

You use this workflow to create, edit, publish, unpublish, and reorder homepage hero slides.

## When you use this feature
- a campaign slide needs to go live
- an existing slide needs maintenance
- the homepage slide order should change

## Where the workflow starts
Hero slides list or Hero slide editor.

## How it works
1. Open the hero slide list or editor.
2. Create or update the slide content.
3. Publish, unpublish, or reorder the slide as needed.
4. Check propagation after the content change reaches downstream caches.

## Expected result
The hero slide set matches the current campaign plan and display order.
