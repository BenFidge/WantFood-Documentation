# Manage Support Local slides

You use this workflow to maintain support-local homepage content and its display order.

## When you use this feature
- support-local content needs refresh
- a slide should go live or come down
- ordering should change

## Where the workflow starts
Support Local slides list.

## How it works
1. Open the current support-local slide set.
2. Create, edit, publish, unpublish, reorder, or remove the right slide.
3. Save the change.
4. Check the downstream experience after caches and content propagation catch up.

## Expected result
Support-local content reflects the current curated message.
