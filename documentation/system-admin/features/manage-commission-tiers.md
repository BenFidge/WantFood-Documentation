# Manage commission tiers

You use this workflow to create, update, or remove the tier rules that drive vendor commission rates.

## When you use this feature
- commercial policy changes
- a tier needs correction
- a vendor commission model should be retired or introduced

## Where the workflow starts
Commissions dashboard -> Commission tiers list.

## How it works
1. Review the current tier catalogue.
2. Create, update, or remove the tier that needs maintenance.
3. Save the change through the admin workflow.
4. Confirm whether related vendors need a follow-up recalculation or assignment review.

## Expected result
The tier catalogue reflects the current commercial policy and is ready for assignment or recalculation.
