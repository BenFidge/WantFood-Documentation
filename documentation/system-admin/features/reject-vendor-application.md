# Reject vendor application

You use this workflow when an application should not progress into onboarding.

## When you use this feature
- the application does not meet platform requirements
- the submitted data is not acceptable
- you need to close out the record without issuing onboarding access

## Where the workflow starts
Applications list -> Application details.

## How it works
1. Open the application record.
2. Review the submitted information and confirm the reason for rejection.
3. Reject the application through the admin action.
4. Confirm that the record is closed and onboarding does not continue.

## Expected result
The application stops at the review stage and the platform does not issue onboarding access.
