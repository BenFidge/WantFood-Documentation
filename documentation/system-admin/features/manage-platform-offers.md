# Manage platform offers

You use this workflow to create, edit, activate, pause, or remove platform-level promotions.

## When you use this feature
- you are launching or closing a campaign
- an existing offer needs maintenance
- you need to change which offer is live

## Where the workflow starts
Platform offers list.

## How it works
1. Review the existing offer set.
2. Create a new offer or open an existing offer.
3. Apply the lifecycle action the campaign needs.
4. Check whether the offer should be monitored through analytics or propagation follow-up.

## Expected result
The active promotion set matches the current campaign plan.
