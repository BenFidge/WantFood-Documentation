# Transfer or remove vendor user

You use this workflow to correct a vendor-linked user relationship or remove vendor access that should no longer exist.

## When you use this feature
- a user belongs to the wrong vendor
- a user should no longer have vendor-linked access
- you need to tidy the relationship between a person and a vendor record

## Where the workflow starts
Vendor users list.

## How it works
1. Find the vendor-linked user.
2. Choose whether to transfer the user or remove access.
3. Complete the action through the admin workflow.
4. Confirm that the user now belongs to the correct vendor record or no longer has vendor-linked access.

## Expected result
Vendor-linked access matches the real business relationship and no stale access remains.
