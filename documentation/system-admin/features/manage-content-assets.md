# Manage content assets

You use this workflow to upload, maintain, or remove shared content assets that other admin-managed content relies on.

## When you use this feature
- a new image or asset is needed
- metadata needs correction
- an obsolete asset should no longer appear in content workflows

## Where the workflow starts
Content asset library.

## How it works
1. Open the asset library.
2. Upload or open the asset that needs maintenance.
3. Apply the metadata or removal action.
4. Allow image processing and propagation to complete before you expect downstream visibility changes.

## Expected result
The asset library contains the right media and downstream content workflows can use it safely.
