# Approve vendor application

You use this workflow when an application meets platform requirements and should move into onboarding.

## When you use this feature
- the submitted business information is complete
- the applicant is suitable for the platform
- you are ready to move the record into onboarding

## Where the workflow starts
Applications list -> Application details.

## How it works
1. Open the application record.
2. Review the submitted business information.
3. Approve the application through the admin action.
4. Confirm that the workflow moves the record into the next onboarding stage.

## Expected result
The application is approved and the onboarding handoff can continue.
