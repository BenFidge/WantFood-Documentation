# Manage bad words

You use this workflow to maintain the blocked-word list that supports content safety.

## When you use this feature
- new blocked terms are needed
- an existing term needs correction
- bulk safety list maintenance is required

## Where the workflow starts
Bad words list.

## How it works
1. Review the current blocked-word list.
2. Add, edit, import, or remove the right entries.
3. Save the updated set.
4. Confirm that the content safety rules now reflect the latest list.

## Expected result
The moderation rule set reflects the current blocked-word policy.
