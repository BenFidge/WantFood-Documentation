# Generate invoices

You use this workflow to create invoice records for one vendor or for a wider monthly run.

## When you use this feature
- uninvoiced activity is ready for invoicing
- a single vendor needs an invoice outside the main run
- finance operations are closing a billing period

## Where the workflow starts
Uninvoiced dashboard or Invoice list.

## How it works
1. Review uninvoiced activity.
2. Choose the right invoice generation path for a single vendor or the wider run.
3. Trigger invoice generation through the admin workflow.
4. Check the resulting invoice records in the invoice list.

## Expected result
The platform creates the invoice records needed for finance follow-up.
