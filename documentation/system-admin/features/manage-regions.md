# Manage regions

You use this workflow to create, update, or remove regions that support targeting and discovery behaviour.

## When you use this feature
- a new region is needed
- an existing region needs correction
- a region should no longer exist

## Where the workflow starts
Regions list.

## How it works
1. Review the current region set.
2. Create, update, or remove the region through the admin workflow.
3. Save the change.
4. Check the affected targeting or discovery experience after normal propagation.

## Expected result
Region data reflects the real operating footprint and downstream behaviour can use it reliably.
