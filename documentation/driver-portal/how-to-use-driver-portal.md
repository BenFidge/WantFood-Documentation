# How to use Driver Portal

You use Driver Portal to complete onboarding, start and end shifts, keep your live location current, manage active deliveries, review route results, maintain weekly availability, and keep your driver profile up to date.

## Start with the right workflow
- Use the onboarding pages when you were just invited and do not yet have a working account.
- Use [Driver dashboard](pages/driver-dashboard.md) as the main signed-in home for work.
- Use [Active deliveries](pages/active-deliveries.md), [Delivery dashboard](pages/delivery-dashboard.md), and [Delivery detail](pages/delivery-detail.md) for live runs.
- Use [Availability schedule](pages/availability-schedule.md) to maintain weekly working patterns.
- Use [Account profile](pages/account-profile.md) when your personal details change.

## Core operating patterns
1. Complete onboarding before you expect the signed-in driver area to work.
2. Start your shift before you expect to appear available for work.
3. Use the live delivery pages to keep delivery state aligned with the real-world run.
4. If route or status behaviour depends on background processing, allow the portal time to return the updated result.
