# Apply availability preset

You use this workflow when a preset lets you update availability faster than changing each slot manually.

## When you use this feature
- a reusable pattern matches your schedule
- you want to set up availability quickly
- manual editing would take longer than using the preset

## Where the workflow starts
Availability schedule.

## How it works
1. Open the availability schedule.
2. Choose the preset that best matches your pattern.
3. Apply the preset.
4. Adjust any exceptions and save the final schedule if needed.

## Expected result
The schedule updates quickly to a useful baseline that you can keep or fine-tune.
