# End shift

You use this workflow when you are done working and should no longer appear available for delivery assignment.

## When you use this feature
- you are finishing work
- you should no longer receive assignments
- the active working period should close

## Where the workflow starts
Driver dashboard.

## How it works
1. Open the dashboard.
2. Run the end-shift action.
3. Confirm that the visible shift state changed.
4. Check that you no longer appear active for new delivery work.

## Expected result
The platform records that you are no longer available for assignment.
