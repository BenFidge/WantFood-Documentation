# Route optimisation

You use this workflow when you want the portal to calculate or refresh the best route for the current delivery work.

## When you use this feature
- you are planning the next stops
- the current route should refresh
- the delivery dashboard should show a better route suggestion

## Where the workflow starts
Delivery dashboard.

## How it works
1. Open the delivery dashboard.
2. Run the optimise-route action.
3. Review the route result when the portal returns it.
4. Clear the route if you need to start over and calculate again.

## Expected result
The dashboard shows the latest route result that the portal can provide for the active delivery work.
