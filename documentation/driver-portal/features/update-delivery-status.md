# Update delivery status

You use this workflow to move a delivery through its working states as the real-world run progresses.

## When you use this feature
- a delivery reaches the next step
- the portal state no longer matches the real-world state
- support needs the delivery record to stay accurate

## Where the workflow starts
Active deliveries, Delivery dashboard, or Delivery detail.

## How it works
1. Open the delivery you are working on.
2. Review the current state and the next valid action.
3. Apply the new delivery status.
4. Confirm that the page reflects the updated state.

## Expected result
The delivery record matches the current real-world stage of the run.
