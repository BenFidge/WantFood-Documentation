# Live location updates

You use this workflow to keep the current driver location flowing while you are on shift.

## When you use this feature
- you are actively working
- delivery progress depends on current location
- dispatch or route views need accurate live position

## Where the workflow starts
Driver dashboard and delivery dashboard.

## How it works
1. Start your shift.
2. Allow the portal to use the expected location context.
3. Check the visible location readback if the site provides it.
4. Continue delivery work while the portal keeps location current.

## Expected result
Live delivery and dispatch views can use fresh driver location data.
