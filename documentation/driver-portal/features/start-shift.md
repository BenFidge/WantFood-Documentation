# Start shift

You use this workflow when you are ready to become available for delivery work.

## When you use this feature
- you are beginning work
- you are ready to accept operational activity
- your availability should become active now

## Where the workflow starts
Driver dashboard.

## How it works
1. Open the dashboard.
2. Run the start-shift action.
3. Confirm that the visible shift state changed.
4. Move into active deliveries or route work as needed.

## Expected result
The platform records that you are now available for delivery work.
