# Update profile

You use this workflow to keep the driver account details accurate.

## When you use this feature
- personal details changed
- support needs the correct contact information
- the current profile data is incomplete or wrong

## Where the workflow starts
Account profile.

## How it works
1. Open the account profile page.
2. Edit the fields that need maintenance.
3. Save the updated profile.
4. Confirm that the page now reflects the latest details.

## Expected result
The driver profile matches the current personal details you want the portal to use.
