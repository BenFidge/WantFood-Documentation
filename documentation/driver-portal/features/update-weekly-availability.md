# Update weekly availability

You use this workflow to maintain the weekly schedule that tells the platform when you are normally available.

## When you use this feature
- your working pattern changed
- you want the schedule to reflect next week accurately
- the current availability view is out of date

## Where the workflow starts
Availability schedule.

## How it works
1. Open the availability schedule.
2. Edit the slots that should change.
3. Save the updated schedule.
4. Recheck that the page now reflects the latest pattern.

## Expected result
The portal shows the weekly availability you intend to offer.
