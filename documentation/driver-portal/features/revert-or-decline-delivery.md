# Revert or decline delivery

You use this workflow when the wrong state was applied or when you should not continue with the delivery.

## When you use this feature
- the current delivery state is wrong
- you need to undo a status change
- you should decline the delivery rather than continue it

## Where the workflow starts
Delivery dashboard or Delivery detail.

## How it works
1. Open the affected delivery.
2. Choose the revert or decline action that matches the situation.
3. Apply the change.
4. Confirm that the delivery now sits in the correct state for follow-up.

## Expected result
The delivery no longer remains in the wrong state and the portal reflects the real situation.
