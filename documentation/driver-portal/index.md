# Driver Portal documentation

This section contains the definitive Driver Portal documentation set for WantFood. Use it when you need the driver handbook, a page reference, or a feature workflow for onboarding, shifts, deliveries, route work, availability, or profile maintenance.

## Features
| Feature | Purpose |
| --- | --- |
| [Start shift](features/start-shift.md) | You use this workflow when you are ready to become available for delivery work. |
| [End shift](features/end-shift.md) | You use this workflow when you are done working and should no longer appear available for delivery assignment. |
| [Live location updates](features/live-location-updates.md) | You use this workflow to keep the current driver location flowing while you are on shift. |
| [Update delivery status](features/update-delivery-status.md) | You use this workflow to move a delivery through its working states as the real-world run progresses. |
| [Mark delivered](features/mark-delivered.md) | You use this workflow when you have completed the handoff and the order is now delivered. |
| [Report a delivery issue](features/report-a-delivery-issue.md) | You use this workflow when a delivery cannot complete normally and the portal should record the problem. |
| [Revert or decline delivery](features/revert-or-decline-delivery.md) | You use this workflow when the wrong state was applied or when you should not continue with the delivery. |
| [Route optimisation](features/route-optimisation.md) | You use this workflow when you want the portal to calculate or refresh the best route for the current delivery work. |
| [Update weekly availability](features/update-weekly-availability.md) | You use this workflow to maintain the weekly schedule that tells the platform when you are normally available. |
| [Apply availability preset](features/apply-availability-preset.md) | You use this workflow when a preset lets you update availability faster than changing each slot manually. |
| [Update profile](features/update-profile.md) | You use this workflow to keep the driver account details accurate. |
