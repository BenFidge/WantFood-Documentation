# Error page

You see this page when a public or signed-in Driver Portal request cannot complete.

## What you need first
- None beyond access to the failed route.

## How you reach it
Any failed Driver Portal route or action.

## What you can do here
- understand that the current action failed
- decide whether to retry, go back, or ask for help
- capture the visible state if support needs it

## What good looks like
You know the current workflow did not complete and you can choose a safe next step.
