# Delivery dashboard

You use this page to manage route information, live delivery state, and map-backed delivery work from one place.

## What you need first
- A signed-in driver account.
- A delivery that needs active work.

## How you reach it
Active deliveries -> open a delivery dashboard or route view.

## What you can do here
- review the route and current stop context
- update delivery status
- run route optimisation or clear route actions

## What good looks like
You can manage the current delivery run from one working page.
